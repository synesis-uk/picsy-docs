title: "Target Search"
description: "Find areas that match the conditions you care about."
---

Target Search lets you search across map hexes using selected measures and thresholds, then review the matching areas on the map.

## Start a search

1. Open **Target searches** from the main navigation.
2. Select **New search**.
3. Open **Search Hexes** and add the measures and thresholds you want to use.
4. Run the search and review the matching areas on the map.
5. Save the search if you want to return to it.

Keep the first search simple. Start with the one or two conditions that matter most, then add more filters if the result is too broad.
