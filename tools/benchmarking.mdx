title: "Benchmarking"
description: "Compare a saved list of locations across a consistent set of measures."
---

Benchmarking helps you compare several locations side by side instead of reviewing each site separately.

## Start a benchmark

1. Open **Benchmarking** from the main navigation.
2. Select **New list**.
3. Name the list and add the locations you want to compare.
4. Open the list to choose the catchment, metric group and comparison.

Use the same catchment across the list for a direct comparison, or switch to per-location catchments where the job calls for it.

You can download a benchmark list as a CSV from the Benchmarking page.
