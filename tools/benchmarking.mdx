title: "Benchmarking"
description: "Compare locations side by side using the same measures."
---

Benchmarking brings several locations into one view, so you can compare them without opening each analysis separately.

## Create a list

1. Open **Compare** from the main navigation.
2. Select **New list**.
3. Enter a name and select **Create list**.

<img className="docs-screenshot" src="/images/guides/benchmark-new-list.png" alt="New benchmark list dialog with the Name field and Create list button." />

PICSy creates an empty list and opens it for you.

## Add locations

Use **Add item** to choose where each location comes from, then search for and select it. Depending on what is available, you can add:

- A saved site
- An address or postcode
- A care home
- A planning record

Repeat this until the list contains everything you want to compare. To take something out, use **Remove** on its row.

## Set the catchments

Open **Catchment** and choose how PICSy should calculate the area around each location:

- **Shared** applies one catchment type and range to the whole list.
- **Per item** lets you set a different catchment for each location.

A shared catchment is usually the clearest choice when you want a direct comparison. Per-item catchments are useful when each location needs its own realistic market area.

## Choose the measures and comparison

Open **Metric group** to choose the measures shown in the list. You can then use **Comparison** to compare each location against:

- The current list average
- A specific location in the list
- Another saved list average
- A saved group average

Use **Columns** to change which fields are visible in the table.

## Review and export the list

The workspace has three result views:

- **List** shows the values for each location and how they differ from your comparison.
- **Charts** visualises the differences across the list.
- **Reports** shows the latest reports for care homes in the list.

Select **Download CSV** to export the current benchmark list. You can also download a saved list from the main Benchmarking page.
