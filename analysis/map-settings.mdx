---
title: "Map settings"
description: "Change the base map and control the layers shown in an analysis."
---

Map settings change how the analysis is displayed. They do not change the site's location or catchment figures.

## Change the map style

Open **Map style** at the top of the workspace, then choose:

- **Monochrome** for a quiet background behind data layers
- **Standard** for a familiar road map
- **Terrain** for landscape and relief context
- **Satellite** for aerial imagery
- **Photorealistic 3D** for a three-dimensional view where available

For supported styles, use the **3D** control to tilt the map without changing the base style.

## Show or hide layers

Open the layer panel on the right of the workspace. Use each layer's switch to show or hide it. Available layers depend on the current analysis view and can include the site, catchment, care homes, planning records and a related built-up area.

Some layers also have style controls for colour, opacity or labels.

<Tip>
  Start with a quiet base map and only the layers needed for the point you are making. This usually produces the clearest report and screen capture.
</Tip>
